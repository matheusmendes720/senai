# Barbearia Noble — Landing Page

Landing page responsiva para a Barbearia Noble, com carrossel de imagens, vídeo embed, lista de serviços, equipe, depoimentos e contato.

## 🔗 Link do Deploy

**[https://matheus-mendes.github.io/senai/](https://matheus-mendes.github.io/senai/)**

*(Aguardar ~2 minutos após o push para o GitHub Pages propagar.)*

## ✨ Recursos

- Carrossel de imagens com Swiper.js (autoplay, navegação touch)
- Vídeo embed responsivo (YouTube)
- Seções: Hero, Serviços, Galeria, Vídeo, Equipe, Depoimentos, Contato
- Botão flutuante de WhatsApp
- Design responsivo (mobile-first)
- Paleta: preto carvão + dourado vintage

## 🛠️ Tecnologias

- HTML5 + CSS3 + JavaScript (vanilla)
- [Swiper.js 11](https://swiperjs.com/) via CDN
- [Font Awesome 6](https://fontawesome.com/) via CDN
- [Google Fonts](https://fonts.google.com/) (Oswald + Roboto)
- Imagens: [Unsplash](https://unsplash.com/)

## 🚀 Como rodar localmente

Basta abrir `index.html` no navegador. Não precisa de build.

## 📤 Deploy no GitHub Pages

1. `git add .`
2. `git commit -m "feat: landing page barbearia"`
3. `git push -u origin main`
4. Em **Settings → Pages** do repositório, selecionar branch `main` / root.
